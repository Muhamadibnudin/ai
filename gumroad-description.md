# AI People Search — Public Information Finder

Search and organize publicly available information from across the web.

### Included
- Mobile-first frontend
- Node.js/Express backend
- Public news search
- Public web/profile discovery
- Social-platform search shortcuts
- Source links and verification
- Identity-match caution labels
- Source confidence score
- News timeline
- Local search history
- HTML / JSON / TXT export
- `.env.example`
- Installation and deployment guide

### Important
This product is designed for public-information research. It does not search private accounts, leaked databases, passwords, private home addresses, private phone numbers, or bypass authentication/CAPTCHA.

### Requirements
Node.js 18+ and an internet connection. Some optional search/AI functionality requires a compatible provider and may have usage limits.

### Product positioning
"Search and organize publicly available information from across the web."

Do not advertise the product as a way to obtain private personal information.
