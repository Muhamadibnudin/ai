# ProposalForge AI — Freelancer Proposal Generator

A zero-API browser app that creates structured prompts for AI assistants.

## Use
Open `app/index.html` in a browser. Paste a job post, add your real skills, choose options, click Generate, then copy the prompt into your preferred AI assistant.

## GitHub Pages
For the easiest deployment, copy the three files inside `app/` to the repository root, commit them, then GitHub → Settings → Pages → Deploy from branch → main → /(root) → Save.

## Included
- Browser app
- 120 prompt templates
- Proposal templates
- Examples
- Documentation

## Important
This is a prompt generator, not an AI API client. It does not send job data to a server. Only sell original code/content and assets you have redistribution rights for.
